---
name: Wordfeud random layouts
description: Product support for random bonus layouts and the limits of screenshot-based bonus recovery.
---

Wordfeud random-layout mode is part of the supported product scope, not an invalid or unrecognized board.

**Why:** The user confirmed that Wordfeud has random-layout mode and asked the helper to handle it, including an empty-board screenshot with non-classic bonus positions.

**How to apply:** Carry the actual scanned bonus layout through board display, solving, saved positions, and letter-confirmation paths. Never silently use classic bonuses for a random board.

Bonuses covered by existing tiles cannot be recovered from a screenshot and should not be invented.

**Why:** Wordfeud consumes a bonus on the turn a tile is placed. Covered bonuses are unnecessary for scoring future moves, whereas substituting classic positions would create incorrect scores.

**How to apply:** Score existing tiles without reapplying bonuses. If the user removes a played tile to reconstruct an earlier position, its hidden bonus requires manual correction rather than inference.
