# Wordfeud Helper

A Dutch-first mobile Wordfeud helper that validates every crossing word.

See [AGENTS.md](./AGENTS.md) for shared project context and continuation notes.

For a browser-accessible version on your own network, see [Self-hosting with Docker, Ollama, and an existing Caddy](SELF_HOSTING.md). The container serves the web app and API; native Android/iOS packages are separate Expo builds.
